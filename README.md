# Eventogen Mailer

A self-hosted, Brevo-style **email marketing & bulk email platform** where users
connect **their own SMTP accounts** (Gmail / Google Workspace, Brevo, Amazon SES,
Mailgun, SendGrid, or any custom SMTP) and the platform handles campaigns,
scheduling, multi-SMTP rotation, tracking, automation and analytics.

> The platform never sends through a shared service — every email goes out
> through the user's own connected SMTP account.

Built to run on **plain PHP 8.2 + MySQL** with **no Composer, no Node.js and no
Docker** — ideal for Hostinger (or any) shared hosting.

| **Automation** | Visual workflow builder: `Email → Wait → Follow-up → …` with stop conditions |
| **Tracking** | Open pixel, click rewriting, device/browser, country (via CDN header), timestamps |
| **Unsubscribe** | One-click (RFC 8058), global + per-campaign suppression, auto contact status update |
| **Analytics** | Per-campaign and per-SMTP reports, delivery log |
| **Admin** | Manage users, assign plans, monitoring, revenue (MRR), system logs |
| **UI** | Bootstrap 5 SaaS layout, light/dark mode, responsive sidebar, data tables, charts |

## 🚀 Installation

### Option A — Installation wizard (recommended)

1. Upload the project to your host.
2. Point your domain's **document root to the `public/` folder**.
3. Create a MySQL database + user in hPanel.
4. Visit `https://yourdomain.com/install/` and follow the wizard. It checks
   requirements, writes `config/config.php`, imports the schema and creates your
   admin account.
5. **Delete the `public/install/` folder** afterwards.

### Option B — Manual

1. Create the database and import `database/schema.sql`.
2. Copy `config/config.php` and fill in DB credentials, `APP_URL`, a random
   `APP_KEY` (32+ chars) and a `CRON_KEY`.
3. Create `config/installed.lock` (any contents) to disable the wizard.
4. Default admin: **admin@eventogen.com / Admin@123** — change it immediately.

## 🛰️ Hostinger deployment guide

1. **Upload** via File Manager / FTP to e.g.
   `~/domains/yourdomain.com/` and put the app in a folder, or upload `public/`
   contents into `public_html` and the rest above it.
2. **Document root** → set to the project's `public/` directory
   (hPanel → Advanced → *PHP Configuration* / subdomain docroot). If you cannot
   change it, the root `.htaccess` will route requests into `public/` for you.
3. **PHP version** → select **8.2** in hPanel.
4. **Database** → hPanel → *MySQL Databases* → create DB + user, grant all.
5. **Run the installer** at `/install/`.
6. **Cron jobs** → hPanel → Advanced → *Cron Jobs*:

   ```
   */5  * * * *  php /home/USER/domains/yourdomain.com/emailer-tool/cron/send-emails.php
   */15 * * * *  php /home/USER/domains/yourdomain.com/emailer-tool/cron/automations.php
   */30 * * * *  php /home/USER/domains/yourdomain.com/emailer-tool/cron/bounces.php
   ```
   (`bounces.php` is optional — it reads the mailbox you configure under
   Settings → Inbox to auto-suppress bounces and detect replies. Needs the
   PHP `imap` extension; it exits cleanly if that's not enabled.)

   Prefer URL-based cron? Use:
   ```
   */5  * * * *  wget -q -O /dev/null "https://yourdomain.com/cron/send-emails.php?key=YOUR_CRON_KEY"
   */15 * * * *  wget -q -O /dev/null "https://yourdomain.com/cron/automations.php?key=YOUR_CRON_KEY"
   ```

No Docker, no Node, no Composer required.

## 📧 SMTP provider quick reference

| Provider | Host | Port | Encryption | Notes |
|----------|------|------|-----------|-------|
| Gmail / Google Workspace | smtp.gmail.com | 587 | TLS | Use an **App Password** (2FA required) |
| Brevo | smtp-relay.brevo.com | 587 | TLS | SMTP key as password |
| Amazon SES | email-smtp.{region}.amazonaws.com | 587 | TLS | SES SMTP credentials |
| Mailgun | smtp.mailgun.org | 587 | TLS | postmaster@ user |
| SendGrid | smtp.sendgrid.net | 587 | TLS | username = `apikey` |
| Custom | your host | 587/465 | TLS/SSL | anything |

## 🔐 Security

- Passwords hashed with `password_hash()` (bcrypt).
- SMTP passwords **encrypted at rest** (AES-256-CBC + HMAC, key from `APP_KEY`).
- CSRF tokens on every state-changing form.
- All queries use **prepared statements** (SQL-injection safe).
- Output escaped with `htmlspecialchars` (XSS safe).
- Hardened sessions (HttpOnly, SameSite), role-based admin access.
- Open-redirect protection on click tracking; cron endpoints require `CRON_KEY`.

## 🛠️ A note on the sending engine

The brief listed **PHPMailer**. To honour the *"no Composer on shared hosting"*
constraint, this build ships a **self-contained native SMTP client**
(`lib/SmtpMailer.php`) that speaks SMTP directly (STARTTLS/SSL, AUTH LOGIN,
MIME multipart). It needs **zero dependencies** and works on Gmail/Workspace,
Brevo, SES, Mailgun, SendGrid and custom relays. If you prefer PHPMailer, drop
it into `lib/` and swap the implementation inside `Mailer::deliver()` /
`Mailer::sendNow()` — the rest of the app is unaffected.
